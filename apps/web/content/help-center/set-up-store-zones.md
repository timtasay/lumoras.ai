A zone is an area of your store that plays its own audio, such as the entrance, the main floor or the fitting rooms. You create zones under **Sound**, pair the speakers in each area, then give every zone a playlist and a volume. Dayparts let that playlist change on its own as the day goes on.

## What this does

Different parts of a store need different sound. The entrance might carry an upbeat set to draw people in, while the fitting rooms stay calmer and quieter. Zones let you control each area separately from one console, and keep every location on the same plan without visiting each one.

## Create your zones

1. Open **Sound**, then **Zones**.
2. Add a zone and give it a name staff will recognize, such as "Front door" or "Zone A".
3. Pair the speakers or audio players in that area with the zone.
4. Set a volume level for the zone. Areas near the checkout usually need it lower so staff can hear customers.
5. Repeat for each area of the store, then save.

## Add playlists and dayparts

1. Open a zone and choose its default playlist.
2. Add dayparts to change the music by time of day. For example, a calmer morning set, a higher-energy set from 4 PM, and a wind-down set for the last hour.
3. Set the days each daypart runs, so weekends can sound different from weekdays.
4. Save. The zone switches sets on its own at each time you set.

## Roll out to more locations

If you run several stores, set up one location first and use it as the template. Copy its zones and dayparts to other locations from the console, then adjust names and volumes for each floor plan. Changes made centrally reach every location that uses them.

## Check that it worked

1. Stand in each zone and confirm the right music is playing at the right level.
2. Walk between zones and listen for overlap. Neighboring zones should not compete with each other.
3. Check the console. Each zone should show as online with its current playlist.
4. Wait for the next daypart change, or adjust a start time to now, and confirm the music switches.

## Troubleshooting

- **A zone shows as offline.** Check that the speaker or player has power and a network connection, then pair it again.
- **Two zones bleed into each other.** Lower the volume in one, or angle the nearest speakers away from the boundary.
- **The music changes at the wrong time.** Check the store's time zone in **Settings**.
